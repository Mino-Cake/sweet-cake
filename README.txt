MINO CAKE WEBSITE

Cara melihat:
1. Ekstrak folder/ZIP ini.
2. Buka index.html menggunakan browser (Chrome disarankan).
3. Pastikan folder assets tetap berada di samping index.html.

Isi:
- Video brand autoplay muted di bagian paling atas.
- Katalog 4 menu, paket bundling, custom order, Instagram, TikTok, WhatsApp.
- Tombol bunga di pojok kanan bawah membuka dashboard pemilik.
- Kata sandi demo dashboard: MINO0993.

PENTING — batasan dashboard:
Website statis ini mencatat klik tombol pemesanan sebagai pesanan "Menunggu konfirmasi" di localStorage browser yang digunakan. Klik WhatsApp tidak dapat membuktikan bahwa pelanggan benar-benar mengirim pesan, membayar, atau menyelesaikan transaksi. Pemilik perlu mengubah status menjadi "Lunas" atau memasukkan transaksi secara manual. Data hanya tersimpan pada browser/perangkat tersebut, tidak tersinkron antar perangkat.

Kata sandi yang ditanam di file HTML/JavaScript dapat dilihat oleh orang yang memeriksa source code, jadi dashboard ini belum aman untuk penggunaan produksi. Untuk laporan otomatis lintas perangkat dan akses pemilik yang benar-benar privat, diperlukan backend/database dan integrasi WhatsApp Business Platform (webhook) atau sistem kasir/pembayaran.
